## Escenario elegido

Escenario B – Análisis de Ventas de una Pequeña Empresa.

## Objetivo

Analizar un conjunto de datos de ventas para obtener indicadores de desempeño comercial.

## Dataset utilizado

Dataset de ventas comerciales simulado en formato CSV.

## Indicadores calculados

* Ventas totales.
* Producto más vendido.
* Ventas por mes.

## Resultados generados

* Resumen de ventas.
* Archivo CSV con ventas mensuales.
* Gráfico de evolución de ventas.

## Estructura del repositorio

/datos
/scripts
/resultados

## Ejecución

1. Abrir Google Colab.
2. Clonar el repositorio.
3. Ejecutar el script analisis_ventas.py.
4. Consultar los resultados generados en la carpeta /resultados.
